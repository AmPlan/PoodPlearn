# Pathumma Whisper (CTranslate2 Version)

This repository contains the CTranslate2 converted weights of [Pathumma Whisper](https://huggingface.co/nectec/Pathumma-whisper-th-large-v3) originally developed by the NECTEC. 

This conversion was created to allow for faster, more memory-efficient inference using the `ctranslate2` library. All credit for the original training, dataset curation, and model architecture belongs to the original creators.
